# pumice_env_allowlist.txt — known engine env-var names for the AMMO env guards.
#
# Read by ammo-env-default-guard.sh (Claude) and pre_tool_use_guard.py (Codex).
# One env name per line. Blank lines and lines that start with "#" are ignored.
#
# PUMICE_* rule (a .py or .rs edit):
#   - a PUMICE_* env name NOT in this list is a new engine env -> BLOCK.
#   - a change to the default of a PUMICE_* name IN this list      -> BLOCK.
# VLLM_* rule (an envs.py edit): the VLLM_* names below default on by design,
# so the guard does not treat them as campaign gating flags.
#
# Seed (run at Pumice 9d126713, from AWSMantlePumice):
#   grep -rhoE 'PUMICE_[A-Z0-9_]{3,}' src pumice-rust/src | sort -u \
#     | grep -v -e '_$' -e '^PUMICE_MODELS$'
# That prints 134 PUMICE_* names. PUMICE_MODELS is dropped on purpose: it is the
# _PUMICE_MODELS registry dict in src/pumice/models/registry.py, not an env var.
# The 8 VLLM_* names are the ones read in src/pumice/_envs.py.
# tests/unit/test_env_default_guard_hook.py asserts these counts (134 + 8).
